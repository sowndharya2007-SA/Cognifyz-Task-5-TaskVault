# TaskVault — Smart RESTful Task Management Dashboard

**Cognifyz Full Stack Development Internship — Task 5**  
*RESTful API Integration and Frontend Interaction*

TaskVault is a modern, responsive full-stack task management application featuring a Python Flask RESTful backend and a Vanilla JavaScript frontend powered entirely by the Fetch API. Data is safely persisted across server restarts using structured JSON file storage.

---

## 🚀 Key Features

* **RESTful API Backend**: Full CRUD operations (`GET`, `POST`, `PUT`, `DELETE`) with strict schema validation and HTTP status codes (`200`, `201`, `400`, `404`, `500`).
* **JSON File Persistence**: Automated directory (`data/`) and storage (`tasks.json`) creation with atomic replacement for data integrity.
* **Modern Dashboard UI**: Curated Indigo & Teal color palette on soft light neutrals, modern typography (Plus Jakarta Sans & JetBrains Mono), responsive cards, and micro-animations.
* **Dynamic Metric Cards**: Live interactive statistics for Total, Pending, In Progress, and Completed tasks that also act as quick filters.
* **Real-time Search & Filter**: Search by title or description keyword, filter by Status and Priority, and sort by date, priority, or title.
* **Inline Status Actions**: Rapid status transitions (Start, Complete, Reopen) directly from task cards.
* **Detailed Task Inspector**: Dedicated detail modal fetching individual records via `GET /api/tasks/<id>`.
* **Toast Notification Engine**: Animated real-time success and error feedback with automatic dismissal.
* **Safe DOM Rendering**: Strict XSS prevention utilizing safe DOM text nodes and `textContent`.

## 📡 RESTful API Documentation

### Task Schema
```json
{
  "id": "task-8f92a1",
  "title": "Design RESTful API Schema",
  "description": "Establish endpoint contracts for GET, POST, PUT, and DELETE operations.",
  "priority": "High",
  "status": "Completed",
  "created_at": "2026-10-25T08:30:00Z",
  "updated_at": "2026-10-25T09:15:00Z"
}
```

* `id` *(string)*: Unique identifier auto-generated by the server.
* `title` *(string, required)*: Max 150 characters, non-empty.
* `description` *(string, optional)*: Max 500 characters.
* `priority` *(string, required)*: `Low` | `Medium` | `High` (default: `Medium`).
* `status` *(string, required)*: `Pending` | `In Progress` | `Completed` (default: `Pending`).
* `created_at` *(string)*: ISO 8601 UTC timestamp.
* `updated_at` *(string)*: ISO 8601 UTC timestamp.

---

### Endpoints Overview

| Method | Endpoint | Description | Status Codes |
|---|---|---|---|
| `GET` | `/api/tasks` | Return all tasks (supports `?search=`, `?status=`, `?priority=`) | `200 OK` |
| `GET` | `/api/tasks/<id>` | Return a single task by ID | `200 OK`, `404 Not Found` |
| `POST` | `/api/tasks` | Create a new task after validation | `201 Created`, `400 Bad Request` |
| `PUT` | `/api/tasks/<id>` | Update an existing task | `200 OK`, `400 Bad Request`, `404 Not Found` |
| `DELETE`| `/api/tasks/<id>` | Delete a task | `200 OK`, `404 Not Found` |

### Example API Requests

#### 1. Retrieve All Tasks
```bash
curl -X GET http://127.0.0.1:5000/api/tasks
```

#### 2. Retrieve Single Task by ID
```bash
curl -X GET http://127.0.0.1:5000/api/tasks/task-8f92a1
```

#### 3. Create a New Task
```bash
curl -X POST http://127.0.0.1:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Configure Production Database",
    "description": "Set up PostgreSQL clustering and backup snapshots.",
    "priority": "High",
    "status": "Pending"
  }'
```
*Response (`201 Created`):*
```json
{
  "id": "task-a19c3b",
  "title": "Configure Production Database",
  "description": "Set up PostgreSQL clustering and backup snapshots.",
  "priority": "High",
  "status": "Pending",
  "created_at": "2026-10-25T11:00:00Z",
  "updated_at": "2026-10-25T11:00:00Z"
}
```

#### 4. Update an Existing Task
```bash
curl -X PUT http://127.0.0.1:5000/api/tasks/task-a19c3b \
  -H "Content-Type: application/json" \
  -d '{
    "status": "In Progress"
  }'
```
*Response (`200 OK`):*
```json
{
  "id": "task-a19c3b",
  "title": "Configure Production Database",
  "description": "Set up PostgreSQL clustering and backup snapshots.",
  "priority": "High",
  "status": "In Progress",
  "created_at": "2026-10-25T11:00:00Z",
  "updated_at": "2026-10-25T11:05:00Z"
}
```

#### 5. Delete a Task
```bash
curl -X DELETE http://127.0.0.1:5000/api/tasks/task-a19c3b
```
*Response (`200 OK`):*
```json
{
  "message": "Task 'Configure Production Database' deleted successfully",
  "id": "task-a19c3b"
}
```

## 🛡️ Security & Best Practices

* **XSS Prevention**: Safe DOM construction avoids `innerHTML` for any user-generated text, using `textContent` and `document.createElement`.
* **Atomic File Storage**: `os.replace` prevents corruption in `data/tasks.json` even under concurrent writes.
* **Separation of Concerns**: Clean isolation between Flask REST endpoints, semantic HTML templates, CSS custom-property design tokens, and modular vanilla JS.
